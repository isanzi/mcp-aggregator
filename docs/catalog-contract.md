# catalog 检索契约（当前）

## 一次查询的构成

```
catalog({ query: "<场景词?> <功能词1> <功能词2> …", limit?: 10 })
```

- **场景词可省略**：立创 / easyeda / 嘉立创 / kicad / freecad / 手机 / 浏览器 / github。
  写了就是**硬作用域**——只在这些下游里检索；不写则全量检索。场景词不计入关键词。
- **功能词最多 4 个**，之间是 **或**；超出只取前 4 个，头行会注明。
- 关键词由**调用方（模型）自己拆**：2–4 个短词，不投整句/长短语。
  中文长短语会被当成 1 个关键词，排序信息消失；英文短语会被空格拆成多段。

## 排序

1. 非别名优先（别名兜底排最后）
2. **命中关键词个数**降序
3. 命中「工具名」个数降序
4. 命中「摘要」个数降序
5. 关键词稀有度（1/词频）之和降序
6. 加权分（旧契约的字段权重）降序
7. 工具引用字典序

每行带 `[命中 k/N]` 标记；别名兜底标 `[别名]`。

## 窗口与裁剪

- 默认只列 **10 行**（`limit` 可调）。
- 第 10 名之后只剪「命中 1 个且加权分 < 15」的长尾，**前 10 名一律保留**。

## 零命中兜底

正常规则一条都没有时，按「整词字面出现在字段里」再查一次；命中则头行标注
`（宽松匹配：整词未命中，按子串兜底）` —— 看到这个标记应按弱匹配对待。

## 与旧契约的差异

| 项 | 旧 | 现 |
|---|---|---|
| 多关键词 | 必须全部命中 | 或，按命中数排序 |
| 排序 | 字段加权分 | 命中数 → 名/摘要命中 → 稀有度 → 加权分 |
| 默认窗口 | 40 行 | 10 行 |
| 场景词 | 仅加权（+900 / ×0.05） | **硬作用域** |
| 零命中 | 直接不显示 | 兜底一次（带标记） |
| `rank` 参数 | score/hits | 已移除（传了无意义） |
